## পরিচিতি

**তাসকীন (Taskeen)** একটি হালকা, দ্রুতগতির এবং সম্পূর্ণ অফলাইন-ফার্স্ট ইসলামিক ডেস্কটপ অ্যাপ্লিকেশন (`Tauri 2.0 + Rust + SQLite FTS5 + React + TypeScript + Tailwind CSS`)। কোনো বিজ্ঞাপন, ট্র্যাকার বা ইন্টারনেট নির্ভরতা ছাড়াই দৈনন্দিন ইবাদত, যাচাইকৃত দোয়া-দরূদ, কুরআন খতম ও আত্ম-উন্নয়নের সব টুল এক জায়গায় সাজানো হয়েছে।

---

## মূল ফিচারসমূহ

### ১. কাস্টমাইজযোগ্য হোম ড্যাশবোর্ড
- **লাইভ নামাজ কাউন্টডাউন হিরো**: পরবর্তী ওয়াক্তের বাকি সময়, সেহরি শেষ ও ইফতারের সময় এবং ৫ ওয়াক্ত কুইক স্ট্যাটাস পিল।
- **জুমআ স্পেশাল মোড**: প্রতি শুক্রবার স্বয়ংক্রিয়ভাবে সূরা আল-কাহফ, দরূদ শরীফ ও আসর-মাগরিব দোয়া কবুলের সময়ের বিশেষ কার্ড।
- **তাৎক্ষণিক তাসবীহ (`Space`)**: প্রোগ্রেস বারসহ দ্রুত তাসবীহ গণনা।
- **উইজেট কন্ট্রোল**: সেটিংস থেকে ড্যাশবোর্ডের প্রতিটি কার্ড আলাদাভাবে দেখানো বা লুকানোর সুবিধা।

### ২. দোয়া, দরূদ ও তাহকীক লাইব্রেরি (১৭১+ এন্ট্রি)
- **SQLite FTS5 ইনস্ট্যান্ট সার্চ** (`Ctrl+K`) ও `SHA-256` ডেটাবেজ ভেরিফিকেশন।
- হাদীসের মান (`সহীহ`, `হাসান`), কিতাব ফিল্টার, ফযিলত, প্রামাণিক ঘটনা এবং ১-ক্লিক কপি ও PNG শেয়ার কার্ড।
- **মুখস্থ মোড (Hifz / Blur-to-Reveal)**: আরবি বা বাংলা অর্থ আড়াল করে নিজেকে পরীক্ষা করা ও মুখস্থ মার্ক করা।
- অফলাইন অডিও প্লেব্যাক ও ভয়েস সিন্থেসিস ফলব্যাক।

### ৩. নামাজ, কিবলা, কাযা ও হিজরি ক্যালেন্ডার (১০০% অফলাইন)
- **অফলাইন জ্যোতির্বৈজ্ঞানিক নামাজের সময়**: `Karachi`, `MWL`, `ISNA`, `Makkah`, `Egypt` মেথড এবং হানাফি/শাফিয়ী আসর।
- **SVG কিবলা কম্পাস** ও ১৬ সপ্তাহের নামাজ হিটম্যাপ।
- **কাযা (Qaza) নামাজ ম্যানেজার**: ফজর–ইশা ও বিতরের জমে থাকা কাযা হিসাব, ১-ক্লিক আদায় (`-১`) এবং দৈনিক লক্ষ্য অনুযায়ী সমাপ্তির হিসাব।
- **মাসিক হিজরি ও বাংলা-ইংরেজি ক্যালেন্ডার**: আইয়ামে বীজ (১৩–১৫ হিজরি), সোম/বৃহঃ সুন্নাহ রোজা, রমজান, আশুরা, শবে বরাত ও ঈদ হাইলাইট।

### ৪. কুরআন ও রুকইয়াহ
- **১১৪ সূরার সার্চেবল ইনডেক্স** ও অফলাইন সূরা রিডার।
- **৬০৪ পৃষ্ঠার খতম প্ল্যানার** (৩০ / ৬০ / ৯০ দিনের লক্ষ্য)।
- **রুকইয়াহ শারইয়্যাহ প্লেয়ার**: অটো-লুপ ও স্লিপ টাইমার (১৫ / ৩০ / ৬০ মিনিট)।

### ৫. ইন্টারেক্টিভ হ্যাবিট ট্র্যাকার, আমল ও লাইফ টুলস
- **ইন্টারেক্টিভ হ্যাবিট ট্র্যাকার**: কাস্টম হ্যাবিট, ৭-দিনের টগল বোর্ড, স্ট্রিক কাউন্টার এবং ৩০-দিনের ধারাবাহিকতা ডট-গ্রিড।
- **দৈনিক মুহাসাবাহ জার্নাল ও নিয়্যত লক্ষ্য**।
- **পার্সোনাল নোটবুক**: টাইটেল, কাস্টম ক্যাটাগরি তৈরি, ১-ক্লিক কপি, এডিট ও রিমুভ।
- **লাইফ টুলস**: ইসলামিক পোমোডোরো, ২.৫% যাকাত ক্যালকুলেটর, সদকাহ লগ ও ওসিয়তনামা।

### ৬. থিম, ফন্ট স্টুডিও, প্রাইভেসি ও ব্যাকআপ
- **৪টি সিগনেচার থিম**: আন্দালুসিয়া, স্যান্ডস্টোন, মিডনাইট, সুবহে সাদিক + কাস্টম অ্যাকসেন্ট কালার ও ইসলামিক জ্যামিতিক প্যাটার্ন টগল।
- **ফন্ট স্টুডিও**: `Noto Sans Bengali`, **কালপুরুষ (অফলাইন বান্ডেলড)**, `Noto Serif Bengali`, `Hind Siliguri`, `Anek Bangla` + `Noto Naskh Arabic` / `Lateef` ও সাইজ স্লাইডার।
- **প্রাইভেসি ও সিস্টেম ট্রে**: ৪–৬ ডিজিট PIN লক, প্রাইভেসি ব্লার মোড, Windows সিস্টেম ট্রেতে লাইভ পরবর্তী নামাজ ও মিনি-তাসবীহ (`Ctrl+Shift+T`), নামাজের ওয়াক্তে নেটিভ নোটিফিকেশন।
- **এনক্রিপ্টেড ব্যাকআপ**: AES-ভিত্তিক লোকাল `.taskeen` ব্যাকআপ ও ঐচ্ছিক E2E ক্লাউড সিঙ্ক (Supabase / কাস্টম URL)।

## কীবোর্ড শর্টকাট

| শর্টকাট | কাজ |
| --- | --- |
| `Ctrl + K` | গ্লোবাল দোয়া ও তাহকীক সার্চ |
| `Ctrl + Shift + T` | মিনি-তাসবীহ ফ্লোটিং মোড |
| `Space` | তাসবীহ কাউন্ট |
| `Esc` | খোলা মোডাল বন্ধ করা |

## লোকাল ডেভেলপমেন্ট ও বিল্ড

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল
npm install

# ২. SQLite তাহকীক ডেটাবেজ তৈরি
npm run build:db

# ৩. ডেভেলপমেন্ট মোডে চালানো (অথবা Start-Taskeen.bat)
npm run tauri dev

# ৪. প্রোডাকশন ইনস্টলার (.exe / .msi) তৈরি
npm run tauri build
```
